# FrameTracker 1.1.0 — Compact arsenal

## Что нового

- Поиск и коллекция теперь выше: большой баннер заменён компактной шапкой с личным прогрессом.
- В инвентаре появились поиск материалов, фильтр дефицита и сброс. На узком экране видно, сколько ресурсов не хватает, без прокрутки вправо.
- В деталях варфрейма добавлен обзор компонентов с переходом к нужному рецепту, включая аспекты Equinox.

## Исправления и улучшения

- Каталог и сводка одинаково различают «Не начат», «В процессе» и «Собран».
- Сводка предупреждает об устаревших ценах отдельно от полноты покрытия. Фактические расходы остаются отдельно от оценки.
- Ошибки сохранения видны вне меню «Данные»; пустые результаты объясняют, как сбросить фильтры.
- RU/EN и прежний формат прогресса сохранены. Поиск варфреймов использует английские игровые названия.

## Обновление Windows

Скачайте **FrameTracker.exe**, закройте предыдущую версию и замените EXE. Прогресс остаётся в профиле Windows; резервную копию можно сделать через **Данные → Экспорт прогресса**. Windows x64, установка и Node.js не требуются. EXE не подписан. **SHA256SUMS.txt** содержит контрольную сумму файла.

## English

- Compact collection header brings search, progress and cards higher on the page.
- Find materials, filter shortfalls and read missing quantities without sideways scrolling on mobile.
- Jump to recipes from the component overview, including Equinox aspects.
- Consistent collection stages, clearer empty results, stale-price warnings and persistent save errors.
- Russian/English support and existing progress remain compatible. Warframe search uses English game names.

**Update:** close the old app and replace it with **FrameTracker.exe** (Windows x64; no installation or Node.js required). Progress stays in your Windows profile. Export a backup from **Data → Export progress**. The executable is unsigned; verify it with **SHA256SUMS.txt**.
