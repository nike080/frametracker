# FrameTracker 1.5.0 — Orokin Legacy

- Redesigned shell, sidebar, collection portraits and component panels inspired by Orokin architecture.
- 23 faction palettes with their own light/dark identity, available embedded emblems and original bilingual thematic mottos.
- One Settings page for appearance, language, progress import/export, relic refresh and market updates, including batch cancellation and individual Prime prices.
- Theme choice survives reload independently of collection progress; invalid preferences safely use the base palette.
- Existing collection, goal, inventory, recipe, undo, price coverage and stale-data behavior retained.
- Keyboard focus, narrow screens and reduced motion supported.

The executable is rebuilt locally as `dist/FrameTracker.exe`. This change does not publish a GitHub release or merge the review branch.
