# FrameTracker 1.7.0 — Сталкер, реликвии и билды

Дата релиза: 13 ноября 2026. Подготовлен в ветке `codex/release-1.7.0`.

- FT-20: официальные локальные иконки Lith, Meso, Neo и Axi рядом с реликвиями в рецептах, справке и онлайн-доступности.
- FT-21: компактные метаданные каталога и источников; подробное объяснение доступности раскрывается по нажатию.
- FT-24: ссылка «Популярные билды · Overframe» в карточке фрейма. Обычная и Prime-версии ведут на одну страницу с рейтингом по умолчанию. Сопоставлены все 119 фреймов; сетевые запросы к Overframe при запуске приложения не нужны.
- FT-27: новая тёмная тема «Сталкер» с алыми акцентами. Применяется по умолчанию; сохранённый выбор прежней темы сохраняется.

Каждая задача реализована в отдельной ветке codex/ft-* и объединена отдельным merge-коммитом. Релиз одобрен владельцем для объединения с main и публикации. OpenSpec: [FT-20](../openspec/changes/archive/2026-11-13-ft-20-relic-icons/validation.md), [FT-21](../openspec/changes/archive/2026-11-13-ft-21-catalog-metadata/validation.md), [FT-24](../openspec/changes/archive/2026-11-13-ft-24-overframe-builds/validation.md), [FT-27](../openspec/changes/archive/2026-11-13-ft-27-stalker-theme/validation.md).

## Проверки

- 37 автоматических тестов: прогресс, каталог, локализация, доступность, Overframe, темы и контраст.
- Внутренний браузер на порту 4191: иконки реликвий Эша Прайм, раскрытие справки, одинаковые ссылки Эша и Эша Прайм, RU/EN, новая тема по умолчанию и сохранение прежнего выбора.
- npm run build:win — успешно, dist/FrameTracker.exe пересобран в релизной ветке.
- npm run test:win — успешно: встроенные ассеты релиза совпадают с исходниками; проверены сохранение, конфликт записи, повторный запуск, резервный порт и перенос EXE. Все процессы portable-проверки закрыты.
- Проверка каталога завершилась без ошибок структуры; прежние пробелы сведений о местах добычи остаются помечены как неизвестные.

## Запуск новой версии

Открыть dist/FrameTracker.exe; выбрать «Сталкер» в Настройках, если ранее сохранена другая тема. Открыть Prime-фрейма и его рецепты; сверить реликвии и ссылку Overframe. Затем проверить привычные операции с прогрессом.

Онлайн-билды требуют интернета и открываются на внешнем сайте; рейтинг и содержимое поддерживает Overframe. Формат сохранений не менялся.
