# FrameTracker 1.2.0 — Personal farming assistant

## Что нового

- Личные цели: выбирайте, каких фреймов собирать следующими, меняйте порядок и смотрите общий дефицит только для них.
- «Продолжить сборку» показывает следующий шаг по рецепту, причину рекомендации и оставшиеся потребности цели.
- Справка рядом с действием содержит известные места получения, ротации, дату снимка каталога и ссылки на источники.
- Получение чертежа, готовый компонент и добытые ресурсы можно отмечать прямо из плана. Последнее изменение можно отменить.
- Личные заметки и последнее записанное изменение помогают продолжить сборку после перерыва.

## Учёт запасов

Пустое поле теперь означает «не проверено», а явно введённый **0** — известный нулевой запас. Если количество неизвестно, помощник предложит проверить его. Очистите поле, чтобы снова пометить запас неизвестным.

Прогресс остаётся ручным. Отметка готового компонента не списывает ресурсы: после крафта обновите остатки самостоятельно. Порядок целей не резервирует ресурсы, а подсказки не обещают оптимальный маршрут. Сведения о фарме основаны на снимке каталога **2026-11-10**; условия и текущая доступность могут требовать проверки.

## Обновление Windows

Закройте предыдущую версию и замените её на **FrameTracker.exe** из этого релиза. Прогресс остаётся в профиле Windows. Перед обновлением можно сделать резервную копию: **Данные → Экспорт прогресса**. Ранее не сохранённые количества невозможно восстановить как подтверждённые нули.

Windows x64, установка и Node.js не требуются. EXE не подписан. **SHA256SUMS.txt** содержит контрольную сумму файла.

## English

- Choose and reorder personal collection goals; see their combined material shortfalls.
- Continue collecting shows an explained next step, remaining requirements and contextual acquisition details.
- Record blueprints, crafted components and loot quantities from the plan; undo the latest progress change.
- Goal notes and the latest recorded change survive restarting and progress export/import.
- Empty stock means unknown; an explicit **0** means known empty stock. Clear a field to mark it unknown again.

Stock remains manual: recording a crafted item does not consume materials. Goals do not reserve resources. Advice follows recipe prerequisites and does not promise an optimal route. Source information uses the **2026-11-10** catalog snapshot; conditions and current availability may need checking.

**Update:** close the old app and replace it with **FrameTracker.exe**. Progress stays in your Windows profile. Export a backup from **Data → Export progress**. Windows x64; no installation or Node.js required. The executable is unsigned; verify it using **SHA256SUMS.txt**.
