# FrameTracker 1.4.0 — Удобнее собирать и планировать

## Что изменилось

- Поиск Warframe, тип, статус коллекции, доступность Prime-реликвий и сортировка объединены в одну панель фильтров.
- Цели, их порядок и «Продолжить сборку» вынесены в отдельную вкладку **Мои цели**. Каталог сразу показывает коллекцию.
- Даты, источники и обновление доступности реликвий находятся в свёрнутой справке **О данных реликвий**; актуальность видна снаружи.
- Готовый каркас, нейрооптику или систему можно отметить одним нажатием прямо в строке компонента.
- Рецепты изначально свёрнуты, окно деталей сохраняет размер при раскрытии. Отмена и фокус при изменении статуса сохранены.
- Проверены русская и английская версии и мобильные фильтры.

## Обновление Windows

Закройте старую версию и замените EXE файлом из релиза. Прогресс хранится отдельно в профиле Windows. Резервная копия: **Данные → Экспорт прогресса**.

Windows x64, установка и Node.js не требуются. EXE не подписан. Контрольная сумма — в **SHA256SUMS.txt**.

## English

- Search, frame type, collection status, Prime availability and sorting now share one filter panel.
- **My goals** brings priorities, next actions and result recording together on a separate page.
- Relic data sources, timestamps and refresh live in a collapsed disclosure with a visible freshness indicator.
- Record crafted components directly in their rows with one click. Recipes start collapsed and the detail panel keeps its size. Undo and keyboard focus are preserved.
- Russian, English and narrow mobile layouts were checked.

Close the old app and replace the EXE. Progress stays in your Windows profile; export a backup from **Data → Export progress**. Windows x64; unsigned executable. Verify the file with **SHA256SUMS.txt**.
