# Выбор направления

Выбран **A — Компактный арсенал**. Пользователь разрешил реализацию и коммит в ui-overhaul 13 ноября 2026.

Объём: короткий каталог, поиск/сброс/стадии, адаптивные ресурсы и поиск материалов, обзор компонентов в native dialog, единые стадии, свежесть цен, постоянная ошибка сохранения. Сохраняются RU/EN, API, данные и portable assets. Полный словарь русских aliases не входит в этот этап: вместо неполного списка интерфейс явно подсказывает английские игровые названия.

Статичные A/B/C остаются историей выбора; приёмочная проверка проводится на реализованном UI.
