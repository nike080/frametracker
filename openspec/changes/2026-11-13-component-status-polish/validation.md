# Проверка прямой отметки компонентов

Дата: 13 ноября 2026. Ветка: `codex/collection-ui-polish`.

Приложение запущено через `PORT=4190 npm start -- --no-browser`; проверка выполнена во внутреннем браузере. Старый экземпляр на 4187 не отвечал, поэтому использован отдельный порт.

- Ash, RU: при открытии все рецепты свёрнуты; статусы компонентов доступны снаружи.
- Нажатие «Деталь готова» у каркаса изменило прогресс с 0/4 на 1/4 без раскрытия рецепта; фокус сохранился на выбранной радиокнопке.
- Размер окна до изменения, после отметки и после раскрытия рецепта: 839.99 × 655.19 CSS px, без изменения размеров.
- Отмена восстановила отсутствующий каркас и сохранила раскрытый рецепт.
- На ширине 360 px проверены RU и EN: ширина содержимого окна равна доступной ширине (290 px), горизонтального переполнения нет. Кнопки статусов помещаются с переносом текста.
- Язык возвращён на RU, временный размер экрана сброшен. Тестовая отметка отменена.
- Существующие 23 теста ранее прошли; код при этом браузерном проходе не менялся.

Область проверки: карточка Ash и новый сценарий отметки/раскрытия. Это не полная проверка всех форм и вложенных рецептов. FT-06 повторно не проверялась.
