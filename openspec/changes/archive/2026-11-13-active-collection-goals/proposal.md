## Why

Для личного помощника общий дефицит всей коллекции слишком широк. Нужен законченный цикл выбора цели, просмотра её дефицита и обновления прогресса с отменой ошибки.

## What Changes

- Добавить активные цели в карточку фрейма и компактный список в каталоге с изменением порядка.
- Добавить режим ресурсов «Мои цели / Вся коллекция», явно показывать пустой список целей.
- Добавить отмену последнего изменения прогресса в текущей сессии.
- Сохранять цели при перезапуске, экспорте и импорте; поддержать старые сохранения.
- Предоставить все новые подписи на RU/EN.

## Capabilities

### New Capabilities

- `active-collection-goals`: упорядоченные цели, целевой дефицит, совместимость сохранений и отмена.

### Modified Capabilities

Нет: общий учёт коллекции и ручная семантика запасов сохраняются.

## Impact

public/app.js, model.js, i18n.js, style.css, index.html, тесты и README. Без новых зависимостей и изменения API сервера.
