# FT-23: World dashboard

## Why

Players need a useful landing page that combines current game conditions and their collection workflow. The catalog alone does not provide a daily overview.

## What Changes

Create a visual default home with collection progress, descriptive navigation, live PC world cycles, daily standing reset, Prime rotation, sortie and Nightwave (clarified by user, not fissures).

## Impact

Add a cached server proxy and dashboard modules, update routes and portable packaging. Saved progress remains compatible.
