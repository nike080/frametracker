## Why

FrameTracker’s Russian interface and acquisition notes limit access for English-speaking players. Bilingual support lets users track the same collection in either language.

## What Changes

- Add English translations for all screens, recipe details, and user-facing feedback.
- Add a Russian and English selector at the upper right of the shared header and remember the selected language.
- Generate bilingual catalog labels and acquisition notes on subsequent catalog refreshes.

## Capabilities

### New Capabilities

- `interface-localization`: Russian and English presentation for all collection views with a persistent language selector.

### Modified Capabilities

None.

## Impact

The web UI, generated catalog, and Windows executable assets are affected. The existing progress format and game identifiers are shared by both languages.
