# Варианты распространения FrameTracker

Интерфейс и расчёты находятся в `public/`. Node-сервер отдаёт каталог, запрашивает цены, ограничивает частоту обращений и хранит кеш на диске. Коллекция живёт в браузере и привязана к адресу и профилю. Импорт и экспорт JSON уже позволяют перенести её в другой адрес или окно приложения.

| Вариант | Как выглядит для пользователя | Что потребуется |
| --- | --- | --- |
| **A. Переносимый EXE для Windows** | Скачать один файл, дважды нажать и получить вкладку в своём браузере. | Упаковать Node и ресурсы в EXE, автоматически открывать вкладку после старта, обработать повторный запуск и занятый порт. Сохранить текущий адрес по умолчанию, чтобы тот же профиль браузера подхватил прогресс. Публиковать новый EXE при выпуске. [Node.js SEA](https://nodejs.org/api/single-executable-applications.html) |
| **B. Настольное приложение для Windows** | Скачать установщик, открыть из меню «Пуск» и работать в отдельном окне. | Упаковать текущий интерфейс в Electron. Перенести данные приложения в профиль Windows и проверить сохранение коллекции при переустановке поверх старой версии. Chromium увеличит размер сборки. [Варианты Windows-пакетов Electron](https://www.electron.build/docs/win/) |
| **C. Сайт с возможностью установки (PWA)** | Открыть ссылку с компьютера или телефона. В поддерживаемом браузере можно добавить приложение на рабочий стол или домашний экран. | Разместить интерфейс и каталог, вынести цены в общий серверный сервис с кешем и ограничением запросов. Прогресс на первом этапе хранить в браузере и переносить через JSON. Поддержка установки и доступ без сети зависят от браузера и настроенного кеширования. [Установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) |

Для A и B проверить первый запуск на чистой Windows и отдельно решить вопрос подписи для широкой раздачи. Новый скачанный файл может вызвать предупреждение SmartScreen. [Microsoft SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)

Для C проверить правила публичного использования Warframe.market и держать лимит запросов общим для всех посетителей. Котировки требуют сети во всех вариантах. Для автономного каталога и чек-листов использовать встроенный снимок в A и B либо кеш после первого посещения в C. Портреты сейчас берутся с CDN. [Правила Warframe.market](https://docs.warframe.market/docs/rules/overview/)

Если главная цель — поделиться трекером по ссылке и обновлять каталог для всех сразу, начать с C. Если нужен именно скачиваемый файл для Windows, начать с A. B оправдан, когда важно отдельное окно и привычная установка. Выпуск сразу в нескольких форматах потребует отдельной проверки обновлений и переноса данных для каждого формата.
