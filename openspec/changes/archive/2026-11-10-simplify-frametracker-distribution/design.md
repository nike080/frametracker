## Решение

Windows x64 получает один EXE со встроенными Node.js, интерфейсом и снимком каталога. При запуске приложение поднимает сервер на 127.0.0.1 и открывает браузер. Сначала используется порт 4187, затем 4188, если первый занят другим приложением. Повторный запуск открывает уже работающий экземпляр.

Прогресс портативного приложения хранится в `%LOCALAPPDATA%\FrameTracker\progress.json`. Файл пишется атомарно и содержит ревизию, чтобы устаревшая вкладка не перезаписывала свежие изменения. Кеш цен расположен рядом и обновляется отдельно. Сборка и расположение EXE не определяют путь к данным.

При первом запуске с прежнего адреса и в том же профиле браузера существующий прогресс импортируется при пустом файле данных. Для другого адреса или браузера используется текущий импорт JSON. Исходный запуск через npm сохраняет прежнюю модель хранения. Обновление распространяется заменой EXE после закрытия работающего экземпляра.

Локальный API принимает изменение состояния только с собственного адреса и проверяет ревизию. Если запись не удалась, интерфейс предлагает сохранить экспорт.
