## ADDED Requirements

### Requirement: FT-21: компактные сведения об источниках
The application SHALL implement the following behavior:

Метаданные каталога и происхождение сведений имеют меньший размер и визуальный вес; подробное объяснение доступности раскрывается по запросу. Источники, даты и предупреждения об устаревании сохраняются.

#### Scenario: Use the feature
- **WHEN** the user opens the affected view
- **THEN** the behavior above is available without changing saved progress
