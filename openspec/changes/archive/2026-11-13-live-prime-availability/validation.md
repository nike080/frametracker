# Проверка онлайн-доступности Prime

Дата: 13 ноября 2026. Ветка: codex/live-prime-availability. Статус: пользователь подтвердил работоспособность и разрешил архивирование, слияние и выпуск 1.3.0.

## Проверки

- npm test: 23/23, включая 7 новых проверок обычных/Aya-реликвий, частичной доступности, неизвестности, окончания ротации, повреждённых ответов, кеша, ограничения запросов и сбоев.
- node --check public/app.js, public/availability.js, server.cjs: пройдено.
- OpenSpec live-prime-availability --strict: пройдено.
- npm run build:win: EXE собран с availability.js. npm run test:win: пройдено. Запуск portable также проверяет загрузку нового модуля из встроенных assets до открытия сервера.
- Реальный локальный сервер на 4193 получил WFCD Relics.json и официальный worldState.php. Warframestat endpoints при исследовании отвечали 404, поэтому реализация от них не зависит.

## Наблюдения интерфейса

- В проверенном онлайн-снимке: 11 полностью доступных Prime-наборов, 40 наборов без новых реликвий в учитываемых ротациях; Excalibur Prime исключён из обычной классификации.
- Фильтр Prime Resurgence: Nidus Prime и Saryn Prime; внутри Nidus Prime основной чертёж связан с Lith S17 у Варзии за Айю.
- Проверены доступные/хранилище, сортировка и RU/EN. Карточки содержат 4/4 либо 0/4 до открытия.
- На узком viewport 390×844 измеренная ширина/scrollWidth равны 375: горизонтального переполнения нет. Настройка viewport сброшена.
- В журнале браузера не обнаружены ошибки приложения.
- Источники получены независимо; время получения и конец ротации видны пользователю. Числа выше — результат конкретного снимка, а не постоянные значения/фикстуры.

## Границы

WFCD может отставать от игры; доступность миссий и событий игроку не проверяется. Классификация описывает новые реликвии обычной ротации по WFCD и активные предложения Варзии за Айю; личные старые реликвии не учитываются. Хранилище не означает «можно только купить». При сбое любого источника вывод консервативно неизвестен. Кеш находится отдельно от прогресса и не включается в его экспорт.

Автоматическое обновление заменяет только панель доступности и каталог карточек, сохраняя ввод заметок; открытая деталь со сфокусированным элементом не перерисовывается до следующего открытия. Полный сценарий сетевого сбоя проверен на уровне сервиса, без изменения системных сетевых настроек.
