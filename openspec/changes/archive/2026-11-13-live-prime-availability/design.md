## Context
Свежий WFCD Relics.json содержит intact-варианты, vaulted и rewards.item.uniqueName. Официальный worldstate содержит PrimeVaultTraders, Activation/Expiry, Manifest/EvergreenManifest. Warframestat endpoints вернули 404 во время исследования; прямой официальный источник ответил 200.

## Goals / Non-Goals
Goals: метки до клика, фильтры, подробности по частям, ручное/автоматическое обновление, честная неизвестность.
Non-Goals: импорт личных реликвий, торговые операции, отдельный каталог всего оружия, автоматическое изменение игрового прогресса.

## Decisions
- Сопоставлять reward uniqueName с ID рецепта, не названиями на разных языках. Использовать только Intact для устранения дублей; вероятности улучшений не выводить.
- vaulted=false означает обычную ротацию по WFCD. У Варзии брать только Projections с RegularPrice >0 без PrimePrice. Преобразовывать StoreItems-путь в item ID. Платные наборы не считаются реликвиями за Айю.
- Учитывать Manifest и EvergreenManifest только в активном интервале [Activation, Expiry). Будущие предложения не считать доступными.
- Все части доступны → available; некоторые → partial; все подтверждённо без новых реликвий → vaulted; отсутствующие/неполные/устаревшие данные → unknown. Основной чертёж включён в счётчик. Прогресс игрока на статус полного набора не влияет.
- Если активная реликвия Варзии не сопоставляется с WFCD, отрицательные выводы ненадёжны: использовать unknown. Не выводить хранилище только из отсутствия строки.
- Общий кеш на 5 минут; ручной повтор не чаще минуты; параллельные запросы объединяются. После 15 минут, сбоя или конца ротации данные не считаются свежими. Старые положительные сведения остаются подсказками с предупреждением.
- Отображать время получения каждого источника, а не объявлять его временем обновления самой базы WFCD. Сервер хранит нормализованный кеш отдельно от прогресса. Сбой записи кеша не обнуляет онлайн-результат.
- Обновлять при входе, возвращении к вкладке и каждые 5 минут в видимой вкладке; обновление карточек не стирает ввод заметок. Текущая открытая деталь со сфокусированным контролом обновится при повторном открытии, чтобы не терять ввод.

## Risks / Trade-offs
WFCD — сторонняя база и может отставать от игры; метки описывают источники, а не гарантированный доступ игрока к миссии. Места получения перечислены как в источнике, включая условные награды. Vaulted не значит «только купить»: остаются старые реликвии, обмен и награды группы. Сбой любого источника даёт консервативную неизвестность.

## Migration Plan
Миграции прогресса нет. При откате disposable-кеш можно игнорировать. Portable EXE должен встраивать availability.js; проверить реальную сборку.
