## Решение
Получать ExportManifest.json через официальный сжатый индекс Public Export. Сопоставлять uniqueName с ID материалов каталога; загружать только PNG с content.warframe.com. Сохранять base64 в одном material-icons.json вместе с URL каждого изображения, manifestId и датой снимка. Снимок заменяется только после успешной загрузки и проверки всех PNG. Обновление: `node scripts/update-material-icons.mjs` после изменения каталога.

127 материалов включают синтетический ID credits. Для него используется официальный значок ежедневного задания CollectCredits; это явное исключение в скрипте и метаданных, не изображение другой валюты.

Один JSON упрощает упаковку существующей portable-сборки и исключает сетевые обращения при показе таблицы. Цена — размер локального снимка и загрузка его при старте. Ошибка загрузки снимка не блокирует приложение.

Общая stockRow выводит слот 36×36 с нейтральной заглушкой и декоративным изображением поверх. При ошибке изображения оно скрывается, слот сохраняет размер. Название и количество остаются текстом; изображения имеют пустой alt и не добавляют повторов для экранного диктора. На узких экранах название переносится.

## Объём
Только материалы (FT-17). Перевод фреймов и закрытие карточек относятся к FT-18/FT-19. EXE включит ассет при следующей запрошенной сборке.
